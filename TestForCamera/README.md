# 质检脚本使用说明

这是一个用于检查板子功能的自动化质检脚本。

## 功能特点

- 自动检查屏幕状态
- 通过SSH连接树莓派
- 检查RP2040访问状态
- 检查SD卡状态
- 拍照测试
- 录音测试
- 自动文件传输
- 结果记录和保存

## 安装依赖

在运行脚本之前，请先安装必要的依赖：

```bash
pip install -r requirements.txt
```

## 使用方法

1. 运行脚本：
   ```bash
   python quality_check.py
   ```

2. 按照提示输入板子ID

3. 按照脚本提示逐步完成各项检查：
   - 屏幕检查：在终端输入y/n
   - 自动连接树莓派
   - 自动检查RP2040和SD卡
   - 拍照前确认：输入y/n
   - 自动录音
   - 文件质量确认：输入y/n

4. 测试结果会自动保存到`testresult.txt`文件中

## 测试流程

1. **屏幕检查** - 询问用户屏幕是否正常
2. **连接树莓派** - 自动SSH连接到192.168.0.235
3. **RP2040检查** - 使用lsusb检查MicroPython Board
4. **SD卡检查** - 使用lsblk检查59.5G设备
5. **摄像头测试** - 拍照并询问用户确认
6. **录音测试** - 录制5秒音频
7. **文件传输** - 将照片和音频传输到本地
8. **质量确认** - 询问用户文件质量
9. **结果保存** - 保存测试结果到文件

## 输出格式

测试结果保存在`testresult.txt`中，格式如下：
```
ID:50 屏幕:1 访问RP2040:1 SD卡:1 摄像头:1 录音:1
ID:55 屏幕:1 访问RP2040:0 SD卡:1 摄像头:1 录音:0
```

其中：
- 1表示通过
- 0表示不通过

## 注意事项

- 确保树莓派IP地址正确（192.168.0.235）
- 确保网络连接正常
- 确保树莓派上的相关目录和工具可用
- 脚本支持连续测试多个板子
